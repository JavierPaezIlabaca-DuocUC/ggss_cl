1. PROJECT OVERVIEW AND PURPOSE
================================================================================

GGSS.cl (Guardia de Seguridad — Sistema de Soporte) is a hybrid multiplatform
digital platform designed for private security guards in Chile. The target
audience is the 100,000+ active private security guards working across Chile.

The app addresses a real gap: security guards lack a centralized, professional
platform to find job opportunities, access training, practice for mandatory
OS10 (Decreto Supremo N°1.773) certification exams, stay current with industry
news, and connect as a professional community.

Core value propositions:
  - Job marketplace: guards find work, employers post vacancies with location
    and WhatsApp contact built in
  - Academic hub: training centers post courses leading to OS10 certification
  - OS10 Simulator: free practice exams with immediate feedback
  - Industry news: aggregated security-sector news via RSS
  - Community forum: peer discussion, experience sharing, advice

The app targets Android as the primary platform (most guards use Android)
while being built as a Flutter multiplatform app (iOS, Web, Windows, macOS,
Linux all supported by the same codebase).

2. COMPLETE TECH STACK
================================================================================

Frontend / App:
  - Framework: Flutter 3.41.9 (stable channel), Dart 3.x
  - State management: flutter_riverpod (providers + AsyncNotifier)
  - Navigation: Flutter Navigator 2.0 (named routes)
  - UI: Material 3 with custom blue/white theme (light & dark mode)
  - Local storage: shared_preferences (settings persistence, link warning prefs)
  - Input formatting: custom PhoneDigitsFormatter (TextInputFormatter)
  - URL handling: url_launcher
  - Maps: Google Maps deep-link integration via url_launcher

Backend:
  - Platform: Supabase (hosted PostgreSQL 15 + PostgREST + GoTrue + Storage)
  - Auth: Supabase Auth (email/password) with custom email templates
  - Database: PostgreSQL with Row Level Security (RLS) on all tables
  - Edge Functions: Deno runtime (deployed on Supabase)
  - Real-time: Supabase Realtime (forum)

Edge Functions deployed:
  - news-proxy: Proxies Google News RSS feed, parses XML, returns JSON news items
  - auth-confirm: Handles email verification deep link redirects (cross-platform)

External APIs:
  - Google News RSS: security-sector news aggregation (via news-proxy Edge Function)
  - Google Maps: address-to-map deep links for job/academic offer locations

Development environment:
  - IDE: VS Code with Flutter extension
  - Version control: Git / GitHub
  - CI/CD: manual (flutter build apk --release)
  - Platform: Windows 11

5. SUPABASE SCHEMA
================================================================================

All tables are in the public schema.
All tables have Row Level Security (RLS) enabled.

--- Table: profiles ---
  id              UUID PK (references auth.users.id)
  full_name       TEXT NOT NULL
  username        TEXT UNIQUE NOT NULL
  rut             TEXT UNIQUE NOT NULL
  phone           TEXT
  account_type    TEXT DEFAULT 'personal'  -- 'personal' | 'empresa'
  bio             TEXT
  avatar_url      TEXT
  show_email      BOOLEAN DEFAULT false
  show_phone      BOOLEAN DEFAULT false
  show_posts      BOOLEAN DEFAULT true
  created_at      TIMESTAMPTZ DEFAULT now()
  updated_at      TIMESTAMPTZ DEFAULT now()

  RLS:
    - SELECT: public (all authenticated users can read)
    - INSERT: auth.uid() = id
    - UPDATE: auth.uid() = id
    - DELETE: auth.uid() = id

--- Table: job_offers ---
  id              UUID PK DEFAULT gen_random_uuid()
  title           TEXT NOT NULL
  company         TEXT NOT NULL
  description     TEXT
  location        TEXT                -- "Región — Comunas" format
  address         TEXT                -- Google Maps searchable address
  salary_min      INTEGER
  salary_max      INTEGER
  contract_type   TEXT                -- indefinido, plazo fijo, honorarios
  modality        TEXT                -- presencial, remoto, híbrido
  whatsapp        TEXT                -- "+56912345678"
  contact_email   TEXT
  created_by      UUID REFERENCES profiles(id)
  created_at      TIMESTAMPTZ DEFAULT now()
  updated_at      TIMESTAMPTZ DEFAULT now()

  RLS:
    - SELECT: public authenticated
    - INSERT: authenticated (created_by = auth.uid())
    - UPDATE: created_by = auth.uid()
    - DELETE: created_by = auth.uid()

--- Table: academic_offers ---
  id              UUID PK DEFAULT gen_random_uuid()
  title           TEXT NOT NULL
  institution     TEXT NOT NULL
  description     TEXT
  duration        TEXT                -- e.g. "40 horas"
  price           INTEGER             -- CLP
  modality        TEXT                -- presencial, online, híbrido
  location        TEXT                -- "Región — Comunas"
  address         TEXT
  whatsapp        TEXT
  contact_email   TEXT
  created_by      UUID REFERENCES profiles(id)
  created_at      TIMESTAMPTZ DEFAULT now()
  updated_at      TIMESTAMPTZ DEFAULT now()

  RLS: same as job_offers

--- Table: os10_questions ---
  id              UUID PK DEFAULT gen_random_uuid()
  question        TEXT NOT NULL
  option_a        TEXT NOT NULL
  option_b        TEXT NOT NULL
  option_c        TEXT NOT NULL
  option_d        TEXT NOT NULL
  correct_answer  TEXT NOT NULL       -- 'A' | 'B' | 'C' | 'D'
  explanation     TEXT
  category        TEXT
  created_at      TIMESTAMPTZ DEFAULT now()

  RLS:
    - SELECT: public (read-only for all, including anon)
    - INSERT/UPDATE/DELETE: service role only (questions managed by admin)

--- Table: forum_posts ---
  id              UUID PK DEFAULT gen_random_uuid()
  title           TEXT NOT NULL
  content         TEXT NOT NULL
  created_by      UUID REFERENCES profiles(id)
  likes_count     INTEGER DEFAULT 0
  comments_count  INTEGER DEFAULT 0
  created_at      TIMESTAMPTZ DEFAULT now()
  updated_at      TIMESTAMPTZ DEFAULT now()

  RLS:
    - SELECT: public authenticated
    - INSERT: authenticated (created_by = auth.uid())
    - UPDATE: created_by = auth.uid() (own posts)
    - DELETE: created_by = auth.uid()

--- Table: forum_comments ---
  id              UUID PK DEFAULT gen_random_uuid()
  post_id         UUID REFERENCES forum_posts(id) ON DELETE CASCADE
  content         TEXT NOT NULL
  created_by      UUID REFERENCES profiles(id)
  created_at      TIMESTAMPTZ DEFAULT now()
  updated_at      TIMESTAMPTZ DEFAULT now()

  RLS: same as forum_posts

--- Indexes (beyond PKs) ---
  idx_job_offers_created_by       ON job_offers(created_by)
  idx_job_offers_created_at       ON job_offers(created_at)
  idx_academic_created_by         ON academic_offers(created_by)
  idx_academic_created_at         ON academic_offers(created_at)
  idx_forum_posts_created_by      ON forum_posts(created_by)
  idx_forum_posts_created_at      ON forum_posts(created_at)
  idx_forum_comments_post_id      ON forum_comments(post_id)

6. EDGE FUNCTIONS DEPLOYED
================================================================================

--- news-proxy ---
  Path:    supabase/functions/news-proxy/index.ts
  Runtime: Deno (Supabase Edge Functions)
  Purpose: Proxies Google News RSS feed to bypass CORS restrictions.
           Queries the RSS feed for "guardia de seguridad Chile",
           parses the XML response, extracts title/link/pubDate/description,
           returns structured JSON array.
  Auth:    Requires valid Supabase JWT (called via supabase.functions.invoke)
  Called by: NewsService in Flutter app

--- auth-confirm ---
  Path:    supabase/functions/auth-confirm/index.ts
  Runtime: Deno (Supabase Edge Functions)
  Purpose: Handles email verification link clicks from any platform
           (Android, iOS, web, desktop). Supabase sends the verification
           link to this Edge Function URL. The function exchanges the
           token with Supabase Auth and redirects to the app deep link
           (ggss://auth/confirm) or a web fallback page.
  Called by: Supabase Auth (email verification link)
  Email template: supabase/email-templates/confirm-signup.html

7. KNOWN LIMITATIONS AND FUTURE IMPROVEMENTS
================================================================================

Current Limitations:
  - Google News RSS via Edge Function may have rate limits; app falls back
    to static curated news when Edge Function is unavailable
  - No push notifications (guards won't get alerts for new jobs or forum replies)
  - OS10 questions are limited to manually entered content; no auto-update
  - Search does not include OS10 questions by design (exam content excluded)
  - No offline mode: app requires internet for all data except static content
  - No pagination on list screens (limited to 20-50 most recent items)
  - Avatar images stored in Supabase Storage with no CDN optimization

Deferred Future Features (explicitly out of scope for this version):
  - Google Sign-In authentication
  - Apple Sign-In authentication
  - English language support / i18n (app is Spanish-only)
  - Push notifications (FCM / APNs)
  - In-app messaging between users
  - Job application tracking
  - Resume/CV upload and storage
  - Admin panel for content moderation
  - Analytics and usage metrics

Technical Debt:
  - Search results are not paginated; large result sets may be slow
  - Forum real-time subscription should have reconnect logic for unstable
    mobile connections
  - No integration tests (unit tests only cover validators)
